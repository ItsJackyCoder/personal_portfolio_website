나에 대한 이야기

다양한 웹 프로젝트를 직접 기획하고 개발하며, 아이디어를 실제 서비스로 구현하는 과정을 경험해 왔습니다. 개발 과정에서 발생하는 오류와 문제를 분석하고 해결하면서, 기능 구현뿐 아니라 사용자 흐름과 편의성까지 함께 고민하는 역량을 키웠습니다. 새로운 기술을 꾸준히 학습하며 더 나은 서비스를 만드는 개발자로 성장하고 있습니다.

HTML, CSS, JavaScript (React, Next.js, Node.js, Express.js, JSX)

Python (Flask, Selenium, Web Crawling, Matplotlib)

Java (Spring Boot, Spring MVC, Spring Data JPA, Spring Security)

Database (MySQL, MongoDB, SQLite, Redis)

자기소개 어떤 일이든 처음부터 완벽하게 해낼 수는 없다고 생각합니다. 하지만 그 과정에서 남들보다 두세 배 더 노력하는 것을 주저하지 않으며, 이러한 끈기와 노력을 통해 기대 이상의 결과물을 만들어내는 데 강점이 있습니다.

기술 스택
포트폴리오 저는 지금까지 총 8개의 프로젝트를 개발하며 프론트엔드와 백엔드 전반의 개발 경험을 쌓았습니다. Java 기반 게임 2개를 비롯해 Python·Flask 기반 개인 금융 웹사이트, Spring Boot 기반 채용 플랫폼, MERN Stack 기반 온라인 강의 관리 플랫폼, React 기반 이미지 탐색 플랫폼을 구현했습니다. 또한 포트폴리오 및 여행 웹사이트를 제작하며 UI/UX와 반응형 웹 디자인에도 집중했습니다. 이를 통해 시스템 로직 구현부터 데이터베이스 및 API 연동, 사용자 인증·권한 관리, 사용자 인터페이스 설계까지 전체 개발 과정을 경험했습니다.

시작하기 위해 잘할 필요는 없지만 잘하기 위해서는 시작해야만 합니다.
